
# Contributing to SecureBank Mini EDR

Welcome to the SecureBank Mini EDR collaborative cybersecurity project.

This repository is maintained as a shared class project. We welcome constructive feedback, bug reports, technical recommendations and code improvements.

## 1. Areas Open for Contributions

Contributions are welcome in the following areas:

- File monitoring and event collection.
- Detection rules and alert accuracy.
- Incident investigation.
- Simulated incident response.
- Event logging and reporting.
- Automated testing.
- Documentation and usability improvements.

## 2. Reporting Bugs and Suggesting Improvements

Before proposing a change:

1. Check existing GitHub Issues to avoid duplicates.
2. Open a new Issue.
3. Clearly describe the problem or proposed improvement.
4. Explain why the change would benefit the project.
5. Include screenshots or examples where appropriate.

## 3. Submitting Code Contributions

For external contributors:

1. Fork this repository.
2. Clone your fork to your computer.
3. Create a separate branch for your changes.
4. Implement the proposed improvement.
5. Run the available automated tests.
6. Commit your changes with a descriptive message.
7. Push your branch to your fork.
8. Open a Pull Request against the main repository.

## 4. Pull Request Requirements

Every Pull Request should:

- Explain what was changed.
- Explain why the modification is necessary.
- Identify affected components.
- Include test results where applicable.
- Update documentation when necessary.

## 5. Project Guidelines

- Do not upload passwords, access tokens or private information.
- Do not commit temporary runtime records.
- Keep changes relevant to the project objectives.
- Test modifications before submitting them.
- Maintain respectful and constructive communication.
- Do not merge unreviewed changes into the main branch.

## 6. Review and Approval

All proposed modifications should be reviewed before being incorporated into the main project.

The repository maintainer is responsible for reviewing Pull Requests and deciding whether proposed changes should be merged.

Thank you for helping improve SecureBank Mini EDR.
